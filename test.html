Advancing Web Browser Forensics: Critical Evaluation of Emerging Tools and Techniques

私密瀏覽並非真正無痕。本研究深入評估五款主流瀏覽器，發現在正常、私密及可攜式模式下皆會殘留數位證據。我們透過系統性測試，揭示了 Chrome、Firefox 等瀏覽器留下的關鍵鑑識產物，為數位調查人員提供了寶貴的證據恢復指南。

網路犯罪日益增長，瀏覽器成為關鍵的數位證據來源。然而，現有鑑識研究常忽略不同瀏覽模式的差異。本研究針對此缺口，全面評估了五大主流瀏覽器（Chrome、Firefox、Brave、Tor、Edge）在正常、私密與可攜式模式下的數據殘留情況。我們設計了四種鑑識場景，利用專業工具分析歷史紀錄、Cookies 等產物。研究發現，即使在標榜匿名的私密模式下，關鍵數位足跡（如搜尋關鍵字、URL）依然可被恢復。本報告為鑑識調查員提供了實用的指南，揭示了不同瀏覽器與模式下的證據恢復潛力，並比較了各種工具的有效性，為打擊網路犯罪提供重要依據。

它們是使用者在瀏覽器中所有行為與互動所遺留下來的數據軌跡。對於數位鑑識調查來說，這些不是無關緊要的垃圾資料，而是如同鑽石般珍貴的直接證據。

最終，透過建立一條精確的活動時間軸，調查人員得以深入理解嫌疑犯的興趣與動機，這在法庭上可能成為決定性的證據。

Anatomy of a Web Browser: Key Components

A browser's architecture consists of several key components that manage user interaction and data processing.

  • User Interface (Front-End): The visual elements a user interacts with (buttons, menus, address bar).
  • Browser Engine: The core component that connects the UI with the rendering engine.
  • Rendering Engine: Interprets and displays web content (HTML, CSS). Different browsers use different engines (e.g., Blink for Chrome, Gecko for Firefox, WebKit for Safari).
  • Networking: Handles internet communication, including HTTP/HTTPS requests and security certificates.
  • JavaScript Interpreter: Executes JavaScript code to enable dynamic and interactive web page features.
  • Data Storage: The backend component responsible for managing local data like cookies, cache, and history.

② 瀏覽器引擎 (Browser Engine)

往下一層，是瀏覽器引擎。你可以把它想像成一個總指揮，它負責協調使用者介面和下一個要講的「渲染引擎」。你點擊一個按鈕、輸入一個網址，都是由瀏覽器引擎來接收指令，然後告訴其他部門該做什麼。

③ 渲染引擎 (Rendering Engine)

接著是核心中的核心之一：渲染引擎。它的任務，就是把那些由 HTML、CSS 寫成的程式碼，轉化成我們肉眼看到的、漂漂亮亮的網頁。

這是不同瀏覽器之間最關鍵的差異點。每個瀏覽器都有自己的心臟。例如，Google Chrome 使用的是 Blink 引擎；Mozilla Firefox 和 Tor 瀏覽器用的是 Gecko 引擎；而蘋果的 Safari 和 iOS 上的 Chrome 則是用 WebKit 引擎。了解用的是哪種引擎，對後續的鑑識分析非常重要。

④ 網路層 (Networking)

再來是網路層。這個元件負責所有對外的溝通。它會處理 HTTPS 這類的安全連線、管理安全憑證，並確保瀏覽器能順利地和遠端的網路伺服器交換資料。

⑤ JavaScript 直譯器 (JavaScript Interpreter)

然後是 JavaScript 直譯器。如果說 HTML 和 CSS 是網頁的骨架和皮膚，那 JavaScript 就是網頁的肌肉和神經。這個直譯器負責執行程式碼，讓網頁能有動態效果、能跟你互動，而不是死板板的一張紙。

⑥ 資料儲存 (Data Storage)

最後，也是對我們鑑識人員最重要的部分：資料儲存。這是瀏覽器的後端元件，它就像一個檔案櫃，負責管理所有我們之前提到的數位麵包屑——也就是那些快取 (Cache)、Cookies 和瀏覽紀錄。這正是我們尋找證據的金礦。

Core Techniques in Web Browser Forensics

Investigators use several techniques to extract digital evidence from browsers:

  • History & Cache Analysis: Examining visited sites, timestamps, and stored web page components (images, scripts).
  • Cookies & Bookmarks Analysis: Analyzing stored user preferences, login data, and saved links to understand user behavior and interests.
  • Download & Password Analysis: Investigating downloaded files and stored credentials to uncover user activities and access protected accounts.
  • Malware Analysis: Scanning for malicious code to understand security breaches and attacker methods.
  • Live & Memory Analysis (RAM): Analyzing data from active programs and volatile memory to capture real-time activities and information that may not be on the disk.
  • Cloud & Extension Analysis: Investigating data from cloud storage and browser extensions, which can reveal user behavior and attempts to hide activity.

① 基礎三劍客：歷史紀錄、快取與 Cookie 分析

首先，是最基本也最關鍵的三項。歷史紀錄分析 (History Analysis)，這不只是看使用者去過哪些網站。鑑識人員會深入分析存取的時間、頻率，甚至是從哪個頁面連過去的。根據研究，這能建立起一份「完整的事件時間軸」，幫助我們理解嫌疑人的行為與興趣。

接著是 快取分析 (Cache Analysis)。大家可以把快取想像成瀏覽器為了加速載入，而暫存在電腦裡的網頁碎片，像是圖片、文字檔、腳本等等。即使原始網頁被刪除，這些碎片依然可能存在，成為拼湊真相的關鍵。

最後是 Cookie 與書籤 (Bookmarks) 分析。Cookie 這種小小的文字檔，記錄了使用者的偏好、登入狀態。而書籤則直接揭示了使用者認為重要、或打算再次造訪的網站。這兩者結合，能非常有效地洞察一個人的「動機」。

② 主動行為的鐵證：下載與密碼分析

第二組技術，聚焦在使用者更主動的行為上。下載分析 (Download Analysis) 會去檢查所有下載過的檔案，無論是文件、圖片還是影片。這些檔案的內容，往往直接揭示了下載背後的意圖，甚至可能包含直接的犯罪證據。

而 密碼分析 (Password Analysis) 則更具侵入性。瀏覽器為了方便，會儲存我們的帳號密碼。鑑識人員可以利用專門工具來提取這些資訊，這不僅能揭露使用者在各網站的活動，甚至有助於破解多個帳戶，擴大調查範圍。

③ 挖掘隱藏的威脅：惡意軟體與雲端擴充功能分析

鑑識不只看使用者做了什麼，也看他的電腦「被」做了什麼。惡意軟體分析 (Malware Analysis) 就是掃描設備中是否有惡意代碼。這能幫助我們追溯惡意軟體的來源網站，並理解駭客的攻擊手法、戰術與程序 (tactics, techniques, and procedures)。

同時，雲端與擴充功能分析 (Cloud & Extension Analysis) 也越來越重要。我們在雲端硬碟的存取、分享、下載紀錄都會被留下。而瀏覽器安裝的擴充功能，本身就是一種證據——例如，一個用來隱藏 IP 位址的擴充套件，本身就暗示了使用者有隱匿身份的意圖。

④ 王牌技術：即時與記憶體分析 (Live & Memory Analysis)

最後，也是最關鍵的技術，是處理「揮發性資料 (volatile data)」。

所謂的揮發性資料，就是那些儲存在 隨機存取記憶體 (RAM) 中，一旦斷電就會消失的資訊。

即時分析 (Live Analysis) 是在電腦還在運行的狀態下，即時監控與收集數據，這能確保嫌疑人無法刪除或修改設定。而 記憶體分析 (Memory Analysis) 則是將整個 RAM 的內容倒出來（也就是所謂的 Memory Dump），再從中尋找那些「從未被寫入硬碟」的證據。這對於調查『無痕模式』下的瀏覽行為至關重要，因為很多活動的痕跡只存在於記憶體中。

Review of Previous Studies: What We Already Know

  • Private Mode is Not Perfect: Foundational studies ([10], [9]) show that private browsing modes in Chrome, Firefox, and Edge still leave behind residual data (cache, cookies) recoverable through forensic techniques, especially from system memory.
  • Browser Privacy Varies: A study of 14 desktop browsers [26] categorized them by privacy levels, finding Brave and Tor offer high protection, while Chrome and Edge offer minimal safeguards by default.
  • TOR is Not Untraceable: Research on the TOR Browser ([13], [22]) revealed that while it offers strong anonymity, it can still leave a considerable number of artifacts in the computer's memory and on the hard disk.
  • Social Media Artifacts: Analysis of Discord within Google Chrome [11] showed that significant forensic data, including user IDs, login tokens, and chat logs, can be recovered from local storage and cache files.

① 私密模式的「不完美」隱私

首先，許多人深信不疑的「私密模式」或「無痕模式」，其實並不如大家想像的那麼無痕。

這是整個領域的一個基礎共識。多項指標性的研究，例如編號為 [10] 和 [9] 的論文，都明確指出，即使是在私密模式下，主流瀏覽器如 Google Chrome、Mozilla Firefox，以及 Microsoft Edge，都依然會留下「殘餘數據」(residual data)。

這些數據，特別是像搜尋關鍵字和登入憑證這類極度敏感的資訊，雖然可能不會寫入硬碟，但它們仍會存在於系統的「記憶體」中。這意味著，只要透過專業的鑑識技術，這些本應被遺忘的數位足跡，完全有可能被還原出來。所以，私密模式更像是「防君子不防小人」的設計。

② 瀏覽器之間，隱私保護大不同

第二點，並不是所有的瀏覽器生而平等。一份針對多達 14 款桌面瀏覽器的大規模評測報告 [26]，給了我們一個非常清晰的圖像：它們的隱私保護等級，可以被劃分為好幾個層次。

  • 報告中發現，像 Brave 和 Tor Browser 這樣的瀏覽器，在預設配置下提供了「高等級」的隱私保護，特別是在抵抗指紋追蹤方面表現優異。
  • 然而，我們日常最常使用的 Google Chrome 和 Microsoft Edge，卻被歸類為僅提供「最低限度」的隱私保護。這點非常值得我們深思。
③ 「洋蔥」不是絕對隱身：TOR 瀏覽器的蹤跡

再來談談被譽為「匿名上網神器」的 TOR 瀏覽器。很多人認為用了 TOR 就絕對安全、無法追蹤。但研究告訴我們，這也是一個迷思。

研究 [13] 和 [22] 發現，雖然 TOR 透過所謂的「洋蔥路由」(Onion Routing) 提供了強大的匿名性，讓追蹤源頭變得極其困難，但它依然會在使用者端的電腦上留下痕跡。鑑識人員或許很難從硬碟的映像檔中找到太多東西，但電腦的「記憶體」卻是另一個故事——分析顯示，相當數量的活動跡證，都可以在記憶體中被發現。TOR 不是真的隱形，它只是把蹤跡藏在了不同的地方。

④ 新興戰場：社群媒體與網頁應用的鑑識

最後，鑑識的戰場也正在轉移。一份針對在 Google Chrome 中運行的 Discord 應用程式的分析 [11] 顯示，大量的鑑識數據，包括使用者 ID (user IDs)、登入權杖 (login tokens)，甚至是完整的聊天紀錄 (chat logs)，都可以從本地端的儲存和快取檔案中被成功還原。這告訴我們，隨著網頁應用越來越複雜，鑑識人員需要關注的目標，已經從單純的瀏覽歷史，擴展到了這些應用程式自身儲存的數據。

Identifying the Gaps: Limitations of Existing Research

Previous studies in browser forensics have several limitations, leaving critical gaps in knowledge:

  • Limited Scope: Many studies focus on only one or two browsing modes, typically normal and private, while neglecting the portable browsing mode.
  • Incomplete Scenarios: Research often fails to cover a comprehensive range of test scenarios involving data retention, clearing history, and memory analysis.
  • Lack of Holistic View: There is a need for a more holistic view of browser behavior across different modes and configurations to accurately assess data leakage points.
  • Our Contribution: This study fills these gaps by analyzing all three modes (normal, private, portable) across four distinct test scenarios using advanced forensic tools, providing a more complete picture of browser artifact retention.

① 這並不是一個無痕的解決方案

首先，最重要的一點是，便攜模式絕對不是一個「無痕」的解決方案。它最大的特點是，它不會將檔案安裝到電腦的系統目錄中，而是將所有使用者資料、快取、歷史紀錄等，全部打包儲存在它自己的根目錄資料夾裡。

這帶來一個有趣的結果：對於鑑識人員來說，這就像是嫌犯把所有證據都整整齊齊地放進了同一個箱子裡。只要我們能取得這個資料夾——無論它是在主機硬碟上，還是在那個被查扣的隨身碟裡——我們就等於掌握了所有活動紀錄的藏寶圖。

② 可還原出的關鍵證物

我們的實驗發現，這個「藏寶箱」裡的內容非常豐富。

首先，我們發現了 IndexedDB 和一個叫做 places.sqlite 的資料庫檔案。這兩個檔案是關鍵，因為它們詳細記錄了使用者曾經訪問過的網站。在我們的案例中，我們清楚地看到了 Brave 瀏覽器留下的 IndexedDB 紀錄。

其次，透過使用像 AccessData FTK Imager 這樣的專業鑑識工具，我們能夠直接從一個叫做 Local Storage 的區域中，提取出使用者訪問過的完整網址（URLs）和他們在搜尋引擎上輸入的關鍵字。

最後，就連網站的縮圖 (Thumbnails) 和記錄使用者偏好的 Cookies 檔案，也都在這個便攜目錄中被完整找到。這意味著我們不只有文字紀錄，甚至還有視覺上的線索。

換句話說，便攜模式並沒有讓證據消失，只是把它們從系統的各個角落，集中到了一個地方。

③ 資料的驚人持久性

最令人驚訝的是這些資料的「持久性」。在我們的測試情境中，即使我們模擬使用者，手動執行了「清除快取」和「清除歷史紀錄」的操作，我們發現像 places.sqlite 這個檔案，以及所有下載檔案的紀錄，依然完好無損地保留在資料夾中。它們根本沒有被刪除。

這表示，只要鑑識人員能取得這個便攜資料夾，無論使用者自認為清理得多乾淨，許多關鍵的瀏覽活動證據，其實都還在那裡等著被發現。

(開場白) 好，我們前面討論了可以找到「哪些」數位證據，但下一個關鍵問題是：「如何」找到它們？這就帶我們進入了鑑識調查人員的工具箱。這也是我們第二個研究問題（R2）：到底哪些工具最適合用來進行網路鑑識採證呢？

① 鑑識工作的本質：組合工具箱，而非單一萬靈丹

首先，我們必須建立一個核心觀念：在網路鑑識的世界裡，並不存在一把可以解決所有問題的「瑞士刀」。就像一位工匠會針對不同的任務使用不同的工具一樣，鑑識人員也需要一個工具組合 (Toolkits) 來進行全面而深入的分析。單一工具絕對不夠，成功的關鍵在於靈活地搭配使用。

② 資料庫偵探：SQLite Browser / DB Browser

我們要介紹的第一個關鍵工具，是 SQLite Browser，也稱為 DB Browser。為什麼它如此重要？因為現代瀏覽器，像是 Chrome 或 Firefox，它們儲存使用者資料的核心機制，就是 SQLite 資料庫。你可以把它想像成瀏覽器的數位檔案櫃。

無論是你的瀏覽紀錄、書籤、還是 Cookies，幾乎所有關鍵資訊都存放在這些 SQLite 檔案中。而 DB Browser 就是讓我們能夠打開這些檔案櫃、查看內容、甚至執行 SQL 查詢來篩選特定證據的必要工具。它讓鑑識人員能像偵探一樣，直接「審問」資料庫，找出需要的線索。

③ 數位複印機：AccessData FTK Imager

接下來是 FTK Imager。這款工具在鑑識領域至關重要，它的核心功能是為磁碟或記憶體（RAM）製作一份精確且無法竄改的複本，也就是我們常說的「鑑識映像檔 (Forensic Image)」。

這一步至關重要，因為它確保了我們所有的分析都是在複本上進行，完全不會動到原始證據，這在法庭上是基本要求。如同我們的研究中所述，FTK Imager 不僅能複製整個硬碟，還能製作出更小、更易於管理的記憶體傾印檔案 (Memory Dumps)。這些映像檔後續還可以搭配解密工具使用，功能非常強大。

④ 數據深潛者：WinHex

如果說 FTK Imager 是複製證據，那麼 WinHex 就是讓我們能潛入數據最深處的工具。它是一款功能強大的十六進位編輯器 (hexadecimal editor)。

當其他工具無法解析某些損毀或隱藏的檔案時，WinHex 讓鑑識人員可以直接檢視最原始的二進位資料。這對於底層數據恢復 (low-level data recovery) 極為關鍵。你可以在記憶體傾印檔案的原始數據中，逐字尋找殘留的關鍵字或 URL 片段。此外，它還能進行雜湊值分析 (Hash Analysis)，確保數據在分析前後的完整性。

⑤ 快速掃描器：專用檢視工具

① 反鑑識技術 (Anti-Forensics) 的興起

首先，最大的挑戰來自於嫌疑人主動採取的反鑑識技術。他們不再只是被動地留下證據，而是會積極地銷毀、隱藏或混淆數位足跡。

這包含了幾種主要手法：

  • 資料刪除與覆寫：這就像是把犯罪現場的文件燒掉一樣，是最直接的手段。
  • 加密 (Encryption)：嫌疑人會將硬碟或特定檔案加密，就算鑑識人員取得了資料，沒有金鑰也只會得到一堆無法解讀的亂碼。
  • 資訊隱藏 (Steganography)：這是一種更為狡猾的技術。嫌疑人可以將機密訊息，例如一份計畫或聯絡人名單，藏在一張看似無害的圖片或一首音樂檔案中。外表看起來一切正常，但內部卻隱藏著關鍵證據。
  • 匿名網路：最典型的例子就是 Tor (Onion Routing)，也就是「洋蔥路由」。它透過在全球多個節點間層層加密與轉發流量，讓追蹤使用者真實的 IP 位址和網路活動變得極其困難。

正如我們的原始研究論文中所提到的，這些技術被用來混淆或銷毀數位證據，讓鑑識人員的工作變得更加艱鉅。

② 瀏覽器擴充套件的干擾

再來，許多為了「增強隱私」而設計的瀏覽器擴充功能，也成了鑑識的阻礙。這些套件可能會自動加密你的瀏覽紀錄、阻擋追蹤器，或隱藏你的真實用戶數據。雖然它們的初衷是保護使用者，但在犯罪調查中，它們卻像一道道屏障，干擾了元數據的收集，讓準確的資訊變得難以獲取。

③ 鑑識工具本身的限制與標準化缺口

最後，我們手上的工具也並非萬能。

  • 工具的限制：許多鑑識工具，例如 DB Browser for SQLite，無法自動偵測不同瀏覽器儲存檔案的預設路徑。這意味著鑑識人員需要大量的手動操作，不僅效率低落，也可能因疏忽而出錯。
  • 缺乏標準化：特別是對於「可攜式瀏覽器」，目前還沒有一套統一的鑑識標準。這些瀏覽器將所有資料儲存在隨身碟等外部裝置上，一旦裝置被移除，大部分證據就跟著消失了，這給鑑識工作帶來了獨特的挑戰。

各位可以想像一下，當調查人員拿到一台電腦，卻要花大把時間手動尋找瀏覽器把資料藏在哪個角落，這有多沒效率？我們的研究也證實，許多現有工具，例如 DB Browser for SQLite，就缺乏自動偵測這些關鍵目錄的能力。這不僅拖慢調查速度，還可能因為人為疏忽而遺漏重要證據。因此，開發出更聰明、能自動化鎖定目標的鑑識工具，是我們的首要任務。

② 第二，我們必須走出 Windows 的舒適圈

本次研究是基於 Windows 11 環境，但現實世界中，犯罪者使用的平台五花八門。他們可能用的是 macOS、Linux，更別提人手一支的 Android 或 iOS 手機。每種作業系統存放與管理資料的方式都截然不同。如果我們的技術只停留在單一平台，無疑是畫地自限。因此，未來的研究必須跨足到所有主流作業系統，才能建立一個真正全面、無死角的鑑識知識體系。

③ 第三，也是最棘手的一點：我們必須正面迎擊「反鑑識」(Anti-Forensics) 技術

這是一場永無止境的貓捉老鼠遊戲。犯罪者會用盡一切手段來銷毀、隱藏數位證據。例如，透過加密或覆寫資料，或是使用像 Tor browser 這樣具備「洋蔥路由」(onion routing) 技術的瀏覽器來隱藏自己的真實 IP 與活動軌跡。此外，各種強調隱私保護的瀏覽器擴充功能，也可能干擾鑑識工作。因此，開發能夠反制這些規避技巧的對策，是未來鑑識領域存活與發展的重中之重。

④ 最後，是關於「可攜式瀏覽器」(Portable web browsers) 的鑑識標準化

這種瀏覽器不用安裝，可以直接在隨身碟上執行。對使用者來說很方便，但對調查人員來說卻是個大麻煩。因為所有資料都儲存在那個可攜式裝置裡，一旦裝置被拔除、銷毀，大部分的證據也就跟著灰飛煙滅。因此，我們迫切需要為這種新興的瀏覽器使用模式，建立一套標準化的鑑識流程與專用工具，確保即使實體裝置不在，我們仍有機會從主機的記憶體中，把殘存的數位軌跡給挖掘出來。

(開場白) 那麼，經過這一系列的分析，我們的研究對於第一線的數位調查人員，究竟帶來了哪些具體的啟示？這就是我們最後的總結。

① 神器殘跡的復原，是鑑識工作的核心

首先，最根本的一點是，從瀏覽器中復原數位神器 (Artifacts)，是整個調查過程的基礎。我們的研究提供了一份詳細的藍圖，展示了哪些工具和技術對於完成這項任務至關重要。

② 沒有任何瀏覽器是絕對的「安全屋」

其次，一個最關鍵的發現是：沒有任何一款瀏覽器是絕對刀槍不入的。即便是在使用者認為最安全的「私密模式」下，所有瀏覽器依然會儲存使用者的活動資料。許多人可能抱持著一種虛假的安全感，以為他們的瀏覽紀錄不會被捕捉，但事實並非如此。

我們的實驗證明，無論瀏覽器如何宣傳其隱私功能，調查人員都不應因為嫌疑人使用了私密模式而卻步。因為證據，依然存在。

③ 這份研究，就是你的實戰手冊

更重要的是，我們今天提出的研究方法，本身就是一份為調查人員設計的實戰指南 (A Methodological Guide)。我們定義了從 M1 到 M4 四種不同的瀏覽情境，並系統性地評估了在正常、私密和可攜式模式下，各種工具的表現。這份指南能幫助你：

  • 第一，根據案件的具體需求，選擇最合適的鑑識工具組合。
  • 第二，預測在特定瀏覽器與模式中，最可能找到哪些類型的證據。 你可以把我們的研究，當作一個校準你現有工具箱的參考基準，從而優化你的辦案效率。
④ 記憶體是等待挖掘的「金礦」

當硬碟上的證據被清除或極為稀少時，請記住，記憶體 (Memory) 就是一座金礦。即使瀏覽紀錄被刪除，像是使用者的搜尋關鍵字和訪問過的 URL 這類極具價值的資訊，依然會殘留在記憶體中，等待鑑識人員透過記憶體傾印 (Memory Dump) 的方式將其還原。

⑤ 持續學習是唯一的道路

最後，瀏覽器的世界是動態變化的，軟體會不斷更新，新的隱私技術也會不斷出現。因此，作為調查人員，我們必須保持持續學習的態度，隨時關注最新的瀏覽器更新和鑑識技術，這樣才能在這場貓捉老鼠的競賽中，始終保持領先。
